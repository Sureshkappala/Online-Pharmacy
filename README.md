# Stackly - Online Pharmacy & Healthcare Platform

A responsive, modern online pharmacy and healthcare e-commerce web application built with vanilla HTML5, CSS3, and JavaScript.

🌐 **Live Demo (GitHub Pages):** [https://sureshkappala.github.io/Online-Pharmacy/](https://sureshkappala.github.io/Online-Pharmacy/)

---

## 🌟 Features

- **Store & Product Catalog:** Browse medicines, wellness products, healthcare devices, and personal care items with categories, filters, search, and sorting.
- **Product Details & Reviews:** View comprehensive medicine details, dosage instructions, active ingredients, and customer feedback.
- **Shopping Cart & Checkout:** Real-time cart management, promo code calculation, order summary, and seamless step-by-step checkout.
- **Prescription Upload:** Secure medicine prescription upload module with instant preview.
- **User Authentication:** Complete login and registration workflows with client-side validation and session simulation.
- **User Dashboard:** Dedicated customer portal with order tracking, refill reminders, prescriptions, and profile management.
- **Admin Dashboard:** Management interface with operational metrics, quick actions, stock tracking, and revenue statistics.
- **Responsive & Mobile-First:** Fluid design with sliding mobile navigation drawer, touch-friendly controls, and cross-browser support.

## 🚀 Quick Start / Local Setup

No build steps or Node.js dependencies required! Simply clone and open:

```bash
# Clone the repository
git clone https://github.com/Sureshkappala/Online-Pharmacy.git

# Navigate to project folder
cd Online-Pharmacy

# Open in browser
# You can open index.html directly or use any local server (e.g. VS Code Live Server, python http.server):
python -m http.server 8000
```

Then visit `http://localhost:8000` in your web browser.
